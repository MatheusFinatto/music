# Musical Tools

Ferramentas de prática para quem toca: gratuitas, sem conta, com foco em guitarra. Um hub leva a ferramentas independentes (tirar de ouvido, afinador, treino de ouvido, improvisação, player de tab e MIDI).

```bash
npm install
npm run build:lab   # uma vez, para o Laboratório aparecer no dev
npm run dev
```

Para desenvolver (pessoas ou agentes): [`CLAUDE.md`](CLAUDE.md), [`docs/ARQUITETURA.md`](docs/ARQUITETURA.md) e [`docs/ROADMAP.md`](docs/ROADMAP.md).
